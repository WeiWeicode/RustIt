## 4. 建議優先順序

1. **資產管理基礎**(財產編號、保管人、狀態、匯出 Excel)+ **舊 SmartIT 資料匯入**:汰換 SmartIT 前一定要有,否則保管資料會遺失。
2. **資安政策框架 + USB 儲存控管**:SmartIT 現在實際在用(有多組 USB 唯讀 / 禁用原則),是汰換的前提。
3. **未安裝 Agent 電腦**、**禁用軟體告警**、**授權報表**:讓 IT 看得到缺口。
4. **報表中心與訂閱**、**CVE 弱點分析**。
5. **關機 / 登出 / WOL**、**遠端協助(RustDesk)**。
6. 稽核類(檔案、網頁、即時通訊、螢幕、列印紀錄)與浮水印:個資與法遵確認後再決定是否做。
