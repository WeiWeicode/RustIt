**執行的主要指令**:

```powershell
# 1. 強制結束 Agent 行程
Stop-Process -Name rustit-agent -Force

# 2. 手動停止 Agent 服務
Stop-Service GigaNexusAgent

# 3. 新增與移除測試軟體登錄機碼 + 下達 inventory.collect
New-Item -Path 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\P5TestApp' -Force | Out-Null
Set-ItemProperty -Path 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\P5TestApp' -Name DisplayName -Value 'P5 Test App'
Set-ItemProperty -Path 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\P5TestApp' -Name DisplayVersion -Value '1.0.0'
Set-ItemProperty -Path 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\P5TestApp' -Name Publisher -Value 'GigaNexus'
Remove-Item -Path 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\P5TestApp' -Force

# 4. 修改 Watchdog 啟動類型為停用
Set-Service -Name GigaNexusWatchdog -StartupType Disabled

# 5. 以一般使用者權限嘗試停止服務
runas /trustlevel:0x20000 "cmd /k sc.exe stop GigaNexusAgent & sc.exe stop GigaNexusWatchdog"

# 6. 解除安裝 MSI
Get-Package "GigaNexus Agent*" | Uninstall-Package
Get-Service GigaNexus*
```

## 4. 可能問題與觀察到的潛在風險

1. **同一台裝置重複觸發竄改事件時,`agent_tampered` 告警保留第一次的 `detail`**:
   - **現象**:`14:45:12` 因 `agent_service_stopped` 開立 `agent_tampered` 告警後,`15:08:11` 再觸發 `watchdog_stopped` 時,`ita.device_alert` 的 `last_seen_at` 有更新(`07:08:11.569Z`),但 `detail` 仍保留第一次的 `agent_service_stopped`(`count: 1`)。
   - **相關檔案**:`ItAgentBack/src/services/alert-service.ts`、`ItAgentBack/src/stores/sql-monitor-store.ts`(見 `docs/P5-MONITOR-DESIGN.md` §8.1「事件類告警:已有未結束的告警時保留第一次的 detail」)。
   - **影響範圍**:設計預期行為(避免覆蓋最初觸發原因),完整歷程可於「事件」Tab 查看;惟未來 P5-3 告警畫面呈現時,建議提示「此為首次觸發摘要,後續事件請見事件分頁」。
2. **GigaItApp 事件 Tab 尚未顯示 P5 新事件類型的中文標籤**:
   - **現象**:目前測試區 GigaItApp 畫面上 `software_updated`、`agent_restarted`、`agent_service_stopped`、`software_installed`、`software_removed`、`watchdog_stopped` 皆顯示原始英文代碼,且尚無「健康與 Agent」與「告警」Tab。
   - **原因**:P5-3(`GigaItApp` 分支 `feature/p5-monitor-ui` 的 `git stash`)依需求方指示暫緩上線。
3. **VM 目前已解除安裝 Agent**:
   - 驗收第 7 項完成後,VM 內的 `GigaNexusAgent` 與 `GigaNexusWatchdog` 處於已移除狀態;後續若要繼續測試 P5-3 畫面或 P6 升級,需在 VM 重新安裝 `GigaNexusAgent-0.6.0-test.msi`。
